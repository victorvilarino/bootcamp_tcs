# Aperfeiçoamento em Inteligência Artificial — TCS

Repositório destinado aos estudos, exercícios e projetos desenvolvidos durante o curso de **Aperfeiçoamento em Inteligência Artificial**, realizado como parte do meu estágio na **TCS**.

O objetivo deste repositório é registrar minha evolução ao longo da formação, reunindo conteúdos de programação, análise de dados, inteligência artificial e atividades práticas desenvolvidas durante o curso.

## 📚 Conteúdos

Ao longo do repositório serão adicionados materiais relacionados a temas como:

- Python
- Manipulação, limpeza e tratamento de dados
- Pandas
- Análise de dados
- Inteligência Artificial
- Machine Learning
- Exercícios práticos
- Projetos desenvolvidos durante a formação
